Instalar NutriControl Diario en tu celular

Acceso directo en tu pantalla de inicio con guardado local por fecha

Android (Chrome / Edge / Samsung Internet)

  1. Abre tu enlace de Vercel en Chrome.
  2. Pulsa el botón Instalar app en la barra superior o abre el menú (⋮).
  3. Selecciona Instalar aplicación o Agregar a pantalla principal.

iPhone / iPad (Safari)

  1. Abre tu URL de Vercel directamente en Safari.
  2. Toca el ícono Compartir (cuadrado con flecha hacia arriba).
  3. Selecciona Agregar a inicio y confirma en Agregar.

Subir a GitHub y publicar en Vercel

Todo el código vive en este único archivo index.html

1. Guarda el archivo como index.html

Colócalo en la raíz de tu carpeta del proyecto. No requiere compilación, Node ni dependencias externas.

2. Súbelo a un repositorio en GitHub

Crea un repositorio nuevo en github.com y sube index.html mediante Add file → Upload files o git push.

3. Impórtalo en Vercel

En vercel.com elige Add New → Project, selecciona tu repositorio y haz clic en Deploy. Obtendrás una URL HTTPS lista para instalar como PWA en tu celular.
